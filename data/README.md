# Data

`chennai_housing.csv` is **synthetic**. It was generated by `chennai_housing/simulate.py` (6,000 properties, fixed random seed), not collected from real listings.

The simulator uses illustrative assumptions: a base rate per square foot for eight Chennai localities, premiums for property type, furnishing, metro access and parking, depreciation with building age, and about 9% random noise for everything the columns don't capture. These numbers are chosen to look realistic, but they are **not market data**.

To use real data, replace this file with listings that have the same columns and run `python -m chennai_housing.model`.

| Column | Meaning |
| --- | --- |
| locality | One of 8 Chennai localities |
| property_type | Apartment, Independent House or Villa |
| area_sqft | Built-up area |
| bedrooms, bathrooms | Room counts |
| age_years | Building age |
| floor | Floor number (0 for houses) |
| parking | Covered parking available |
| near_metro | Within walking distance of a metro station |
| furnishing | Unfurnished, Semi-furnished or Furnished |
| dist_main_road_m | Distance to the nearest main road |
| price_inr | Price in rupees (the target) |
